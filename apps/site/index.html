02 / PHILOSOPHY

大多数编辑器把 Markdown 当成一种输入格式。

handymd 把它当成
文档本身。

01

光标决定界面

离开文字时，标记安静退场；靠近时，完整源码立即显现。界面跟随注意力，而不是模式按钮。

02

每个字都可移植

ProseMirror 中的文档就是 Markdown 字符。复制、保存、同步，不经过另一套模型。

03

为真实写作设计

中文 IME、待办、引用、代码和 Mermaid 都在同一张纸上自然工作。
